# ADF Gestion

Application de gestion des cotisations du groupement ADF.

- `index.html` : l'application (une seule page)
- `config.js` : identifiants du projet Firebase
- `firestore.rules` : règles de sécurité à coller dans la console Firebase (Firestore → Règles)
- `manifest.webmanifest`, `sw.js`, `icons/` : installation sur téléphone

Les données (membres, versements, trésorerie…) sont stockées dans Firebase, jamais dans ce dépôt.
